## 配置与 SDK

本次只在受保护 pages.json 增加直播 6 页和候场/房间的原生组件声明，未改 manifest.json、uniCloud-aliyun 或依赖大版本。API 地址沿用现有配置；本机 127.0.0.1 不是可用真机地址，目标 HTTPS/WSS 与合法域名须由部署环境提供，本次未编造线上域名。

腾讯云密钥仅由后端配置。前端使用官方 `trtc-wx-sdk@1.1.15`，必需 JS 放直播分包，许可、来源和校验见 [SDK 来源](vendor/trtc-wx-sdk/SOURCE.md)。真实微信组件提供 SDK 上下文，不将 Vue 实例冒充原生组件。

Mock 开启时直播明确提示需要真实后端，不返回假开播成功。页面隐藏/卸载或账号变化会退出媒体与订阅；恢复先取快照，不重放旧操作。麦克风默认关闭，用户按主持安排开启；设备检测不上传录音。

舞台变更触发房间换代和旧房间清理，存在真实重连和观众切流成本，必须进行多端验收。H5 仅供流程联调。
